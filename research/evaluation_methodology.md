# Evaluation Methodology

## Security Metrics

### Prompt Injection Detection Rate

Percentage of malicious prompts successfully detected.

### False Positive Rate

Benign prompts incorrectly blocked.

### Human Escalation Rate

Percentage of requests requiring approval.

## Agent Reliability Metrics

### Task Completion Rate

Successful completion percentage.

### Workflow Accuracy

Correct workflow routing.

### Tool Selection Accuracy

Correct tool chosen by orchestrator.
